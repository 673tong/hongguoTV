## 红果 TV 原生版 0.9.0

### 修复

- **播放黑屏**：媒体 CDN 对分段请求可能返回 `200` 与完整内容而不是 `206`，客户端原先强制要求 `206`，导致每一段都抛 IO 错误，表现为播放器「已自动重试 3 次」并停在黑屏。现在与原 Node 服务端行为一致，兼容该响应并切片读取。
- 列表与详情不受影响的部分保持不变。

### 应用内更新

- 更新源改为本仓库 Release，直接读取 GitHub API 最新发布，匹配 `hongguotv-kotlin-*-android8.apk` 资源，按文件名语义化版本比较新旧。
- 每次启动都会检查一次新版本；浏览时发现新版自动下载并提示安装，播放中不打扰。
- Release 不含校验和文件，因此安装前改为校验包名、版本与签名证书是否一致。

### 签名变更（重要）

自本版起使用全新的发布签名：

```
CN=HongguoTV Native, OU=Personal TV, O=HongguoTV, L=Guangzhou, ST=Guangdong, C=CN
SHA-256: 78B9D1F7D57B1ECC8B5B3CB5E95C525A3D9A53455DA5720246E748B57C61C714
```

此前安装的非本签名版本（如旧 `080` 包）**无法覆盖安装**，必须先卸载旧版再安装本版，卸载会清除收藏与观看记录。此后所有版本沿用该签名，可正常覆盖升级。

安装包信息：`com.hongguotv.nativeapp` · 版本 0.9.0 · versionCode 9 · minSdk 26（Android 8.0+）
