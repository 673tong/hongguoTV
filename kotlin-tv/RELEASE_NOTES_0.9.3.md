# 红果 TV 原生版 0.9.3

## 修复

### 在线更新报"更新信息格式不正确"

- 根因：更新器只认旧 CI 命名 `hongguotv-kotlin-*-android8.apk`，而 0.9.2 起发布附件改名为
  `hongguoTV-0.9.2.apk`，正则匹配不到任何安装包，于是报格式错误。
- 修复：同时接受两种命名（`hongguotv-kotlin-<版本>-android8.apk` 与 `hongguoTV-<版本>.apk`），
  大小写严格匹配、依然拒绝路径穿越等异常文件名，安全边界不变。
- **0.9.2 用户需手动安装本包一次**，之后的在线更新恢复正常。

### 播放面板直达倍速 / 清晰度

- 播放界面按 ↑（更多）后，面板里现在直接平铺"倍速"和"清晰度"按钮，
  不必再进"播放设置"二级菜单。原有"播放设置"入口保留（含画面比例、定时、从头播放）。

## 说明：为什么是 360p 而不是 720p

网页版默认 720p 是事实，但那条 DASH 流的样本是 **CENC（AES-CTR）加密**的，
真正的解密密钥由官网播放器内的 `aw.wasm` 模块在浏览器 Worker 里解出，
`play-info` 接口返回的只是密钥信封凭证，不是密钥本身——纯 HTTP 客户端拿不到。
0.9.2 的发布说明与源码注释里都记录了三条可能的突破路径（WebView 跑站点播放器取密钥 /
复现 wasm 解封约定 / 找直出 `spade_a` 的接口），一旦打通会立刻上 720p。
